# Changelog

## 0.1.0 - Initial public release

Initial public release of Emonri.

Features:

- Desktop application for Windows 11 and newer computers
- Desktop application for macOS on Apple Silicon Macs
- Desktop application for macOS on Intel Macs
- Personal photo and video browsing
- Media organization
- Search and rediscovery
- Story creation from photos and videos
- Notes for simple markup documents
- Family sharing at home
