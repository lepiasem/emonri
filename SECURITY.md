# Security Policy

Emonri is a desktop application for personal media. Please do not post private media, credentials, tokens, private file paths, crash dumps, logs with personal data, or unpublished vulnerability details in public GitHub issues.

For security-sensitive reports, use the official Emonri feedback form and include a contact email so the team can follow up:

https://emonri.com/feedback

Supported release targets:

- Windows 11 and newer desktop computers
- macOS on Apple Silicon Macs
- macOS on Intel Macs

The latest supported release is available from:

https://emonri.com/download
