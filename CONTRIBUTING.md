# Contributing

Emonri is proprietary software and this repository is not an open-source development repository.

Please do not submit pull requests with source-code changes, product modifications, binaries, or reverse-engineered materials.

You can share product feedback through the official feedback form:

https://emonri.com/feedback

If a maintainer asks you to report a packaging or release issue on GitHub, include:

- The Emonri version
- Your platform: Windows 11 or newer, macOS Apple Silicon, or macOS Intel
- The package filename or release tag
- What happened and what you expected
- Any error text that does not include private media paths, passwords, tokens, or personal files
